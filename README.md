# 📸 My Photo Album

An interactive photo album built entirely with HTML, CSS, and JavaScript.

## ✨ Features

- **Image Gallery:** Clean and organized display of all photos.
- **Lightbox:** Enlarged view when clicking on an image.
- **Responsive:** Looks great on both mobile devices and desktop screens.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 How to Run

Simply open the `index.html` file in any web browser.
